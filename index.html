Threefold Psychological Services Appointment Management System

Team Falcon. I served as Project Manager and Systems Analyst.

A web platform that replaces Facebook-based booking for a psychological services clinic. Clients choose a service and time, pay, and keep their appointment records in one place, while psychologists and admins manage schedules, payments and history.

The scheduling engine is a separate Python service that uses integer linear programming to assign admin psychologists with the fewest changes to existing bookings, and suggests the nearest open times when a slot is taken.
